# 🚀 Smart Task & Project Manager

A dynamic web application built with **PHP** and **MySQL** to help users organize their projects, manage tasks, and track productivity efficiently.

## ✨ Features
* 📁 Create and manage projects.
* 📝 Add and track daily tasks.
* 🗄️ Persistent database storage using **PDO**.
* 📱 Clean and responsive user interface.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP (PDO)
* **Database:** MySQL (XAMPP / Localhost)
* **Version Control:** Git & GitHub

---

## ⚙️ How to Run Locally
1. Clone this repository to your local machine.
2. Move the folder to your `htdocs` directory (XAMPP).
3. Import `database.sql` into your phpMyAdmin database.
4. Update the database credentials in `config/db.php` if needed.
5. Open `http://localhost/smart-task-manager` in your browser.
